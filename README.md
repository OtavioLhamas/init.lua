# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## markdown-preview.nvim

To fix the [markdown-preview](https://github.com/iamcco/markdown-preview.nvim)
go to the plugin folder ($HOME/.local/share/nvim/lazy/markdown-preview.nvim)
and run `npm install`.
